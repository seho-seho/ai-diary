# 📔 하루 기록 (AI Diary)

대화를 바탕으로 매일 일기 질문을 만들어 주고, 대화·일기 속 일정을 캘린더에 기록하는 웹 일기장입니다.
설치 없이 브라우저에서 바로 열리며, GitHub Pages로 배포됩니다.

## 기능

- **오늘의 질문** — 최근 7일의 일기·대화와 다가오는 일정을 읽고, 오늘 답할 질문 3개를 만들어 줍니다.
- **대화** — AI 일기 친구와 하루 이야기를 나눕니다. 대화 속 "내일 3시 팀플 회의" 같은 일정은 자동으로 캘린더에 들어갑니다.
- **다른 대화 붙여넣기** — 카톡·메신저·다른 AI와 나눈 대화를 붙여넣으면 요약하고 일정을 찾아 줍니다.
- **자유 일기 + 기분** — 자동 저장. "저장하고 일정 찾기"를 누르면 일기 속 일정도 찾아 주고 짧은 코멘트를 남깁니다.
- **캘린더** — 월간 달력에 일정과 일기 쓴 날(기분 이모지)을 표시. 직접 추가·삭제 가능.
- **외부 캘린더로 보내기** — 일정마다 "구글 캘린더에 추가" 링크, 전체 일정 `.ics` 내보내기(구글·아웃룩·애플 캘린더에서 가져오기).
- **백업** — 모든 기록을 JSON으로 내보내고 불러오기.

## 사용법

1. 사이트를 엽니다.
2. ⚙️ 설정에서 [Claude API 키](https://platform.claude.com/settings/keys)를 입력합니다.
3. 대화 탭에서 하루 이야기를 하거나, 일기 탭에서 질문에 답해 보세요.

## 데이터와 개인정보

- 일기·대화·일정·API 키는 **사용하는 브라우저의 localStorage에만** 저장됩니다. 이 저장소(GitHub)에는 어떤 기록도 올라가지 않습니다.
- AI 기능을 쓸 때만 해당 내용이 Anthropic API로 전송됩니다.
- 브라우저 데이터를 지우면 기록도 사라지니 설정 → **백업 받기**를 주기적으로 해 두세요.
- 같은 `*.github.io` 주소 아래의 다른 페이지와 저장 공간을 공유하므로, 공용 컴퓨터에서는 사용 후 API 키를 지워 주세요.

## 로컬에서 실행

```bash
python -m http.server 5317
# http://localhost:5317 열기
```
